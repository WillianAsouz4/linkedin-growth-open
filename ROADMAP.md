# Roadmap — LinkedIn Growth Open

## Visão

Criar uma ferramenta gratuita e open source para planejamento, geração, revisão e análise de conteúdo de marketing pessoal no LinkedIn.

## Fase 0 — Fundação

- [ ] Definir nome final do produto.
- [ ] Definir licença open source.
- [ ] Criar estrutura inicial do projeto.
- [ ] Criar documentação de instalação.
- [ ] Definir modelo de dados.
- [ ] Definir regras de privacidade.

## Fase 1 — Perfil estratégico

- [ ] Cadastrar nicho.
- [ ] Cadastrar público-alvo.
- [ ] Cadastrar objetivo principal.
- [ ] Cadastrar meta de visualizações.
- [ ] Cadastrar frequência de publicação.
- [ ] Cadastrar pilares de conteúdo.
- [ ] Cadastrar palavras preferidas e proibidas.
- [ ] Criar campo para regras de estilo.
- [ ] Permitir salvar exemplos de textos aprovados.

Critério de conclusão: o usuário consegue salvar uma configuração completa para orientar a criação dos posts.

## Fase 2 — Gerador de conteúdo

- [ ] Receber um tema enviado pelo usuário.
- [ ] Gerar três opções de gancho.
- [ ] Gerar um post completo.
- [ ] Gerar chamada para ação.
- [ ] Gerar hashtags relevantes.
- [ ] Sugerir formato do post.
- [ ] Identificar se uma imagem é necessária.
- [ ] Criar prompt para imagem.
- [ ] Gerar uma versão usando o método XYZ quando o tema envolver experiência ou resultado.
- [ ] Permitir editar e regenerar trechos.

Critério de conclusão: um tema gera um rascunho editável alinhado ao nicho e às regras cadastradas.

## Fase 3 — Pontuação do conteúdo

- [ ] Criar pontuação de 0 a 100.
- [ ] Avaliar gancho.
- [ ] Avaliar clareza.
- [ ] Avaliar alinhamento ao nicho.
- [ ] Detectar exemplos, números e evidências.
- [ ] Avaliar chamada para ação.
- [ ] Avaliar estrutura e leitura.
- [ ] Avaliar palavras-chave.
- [ ] Mostrar explicação de cada nota.
- [ ] Gerar recomendações de melhoria.
- [ ] Comparar pontuação antes e depois da edição.

Critério de conclusão: o usuário sabe por que um conteúdo recebeu determinada nota e como melhorar.

## Fase 4 — Rascunhos e calendário

- [ ] Salvar rascunhos.
- [ ] Criar status: ideia, rascunho, revisão, aprovado e publicado.
- [ ] Criar calendário editorial.
- [ ] Filtrar posts por status e data.
- [ ] Duplicar um post para criar uma variação.
- [ ] Exportar conteúdo em Markdown e JSON.

## Fase 5 — Métricas

- [ ] Registrar visualizações.
- [ ] Registrar curtidas.
- [ ] Registrar comentários.
- [ ] Registrar compartilhamentos.
- [ ] Registrar novos seguidores.
- [ ] Registrar leads gerados.
- [ ] Calcular taxa de engajamento.
- [ ] Comparar posts por tema e formato.
- [ ] Mostrar quais pilares geram melhores resultados.
- [ ] Usar os resultados para sugerir novos temas.

## Fase 6 — Perfil e método XYZ

- [ ] Importar texto do perfil.
- [ ] Avaliar título/headline.
- [ ] Avaliar seção Sobre.
- [ ] Avaliar experiências.
- [ ] Detectar descrições genéricas.
- [ ] Sugerir palavras-chave.
- [ ] Reescrever experiências usando X, Y e Z.
- [ ] Criar pontuação do perfil de 0 a 100.
- [ ] Gerar relatório antes e depois.

## Fase 7 — Imagens

- [ ] Gerar descrição visual coerente com o tema.
- [ ] Criar prompt de imagem.
- [ ] Permitir upload manual.
- [ ] Salvar referências visuais aprovadas.
- [ ] Aplicar um guia visual consistente.

## Fase 8 — Qualidade e publicação

- [ ] Criar testes automatizados para o avaliador.
- [ ] Adicionar validação de conteúdo vazio ou incoerente.
- [ ] Criar revisão de segurança e privacidade.
- [ ] Criar exportação pronta para copiar no LinkedIn.
- [ ] Manter publicação manual na primeira versão.
- [ ] Documentar limites e responsabilidades do usuário.

## Primeira entrega

A primeira entrega deve conter somente:

- Configuração do nicho e público.
- Cadastro da meta de visualizações.
- Campo de estilo.
- Entrada de tema.
- Geração de post.
- Pontuação explicada.
- Salvamento do rascunho.

Não adicionar publicação automática antes de validar esse fluxo.
